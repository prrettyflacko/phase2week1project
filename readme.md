# 👁️ Computer Vision Streamlit Hub

Интерактивное веб-приложение на базе **Streamlit**, объединяющее четыре специализированные модели искусственного интеллекта для компьютерного зрения. Проект позволяет загружать фотографии, получать мгновенные предсказания ИИ, а также детально изучать метрики эффективности каждой модели.

---

## ✨ Основные возможности

* **Интуитивная навигация**: Удобное боковое меню для быстрого переключения между четырьмя ИИ-модулями.
* **Инференс в реальном времени**: Простая загрузка пользовательских изображений (JPG, PNG) и мгновенный вывод предсказания класса.
* **Прозрачная аналитика**: Каждая модель содержит интерактивную вкладку с метриками, где наглядно показана история обучения и качество работы ИИ.

---

## 🧠 Доступные ИИ-модули

Проект включает в себя 4 независимых нейросетевых модуля, каждый из которых решает свою уникальную задачу классификации:

1. 🩸 **Анализ клеток крови** — распознавание и классификация различных типов клеток по медицинским снимкам.
2. ⚽ **Классификация спорта** — определение конкретных видов спорта по действиям и инвентарю на фотографии.
3. 🌲 **Снимки Intel (Природа)** — распознавание и разделение природных ландшафтов (горы, леса, моря, пустыни, городские постройки).
4. 🌦️ **Классификация погоды** — автоматическое определение погодных условий и атмосферных явлений по внешним признакам.

---

## 📊 Аналитика и Метрики

Для каждого ИИ-модуля реализован полноценный аналитический экран, который включает в себя:
* **Динамику обучения**: Графики изменения точности (Accuracy) на обучающей и валидационной выборках по эпохам.
* **Матрицу ошибок (Confusion Matrix)**: Детальную визуализацию предсказаний модели, позволяющую увидеть, между какими классами ИИ колеблется чаще всего.
* **Рекорды моделей**: Фиксацию лучших результатов (например, достижение супер-рекордов точности на финальных этапах штурма/Stage 4).
